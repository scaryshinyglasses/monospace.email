A FEW LAST THINGS

Before you
press enter.

Do I need to change email providers?+

No. Connect Gmail, Outlook / Microsoft 365, or an IMAP + SMTP account. Several accounts appear together in one folder tree.

Will images work in my terminal?+

Monospace automatically detects Kitty graphics and Sixel in compatible terminals. Other terminals use coloured half-blocks. Remote images are blocked by default; press i to load them.

Do I need an AI agent to use it?+

No. Monospace is a complete terminal email client on its own. The MCP server and JSON CLI are there when you want to connect an agent or write a script.

Is it really free and open source?+

Yes. Monospace is MIT licensed. Read the source, report a bug, or contribute on GitHub.
